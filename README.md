# My first repository also first project

## ROCK PAPER SCISSORS GAME
This program is written in Python, used input validation to check user's input is either rock, paper, or scissors, used
while loop to loop the program if the user want to play again, also used if, elif condition to check conditions and write
the program's pattern.

HOW TO RUN: 1. OPEN TERMINAL USING THE CTRL + ` (BACKTICK). 2. TYPE python main.py 
HOW TO PLAY: 1. CHOOSE EITHER ROCK, PAPER OR SCISSORS. 2. THE RESULT WILL COME, EITHER YOU WIN OR THE ROBOT WINS. 3. YOU'LL
BE ASKED IF YOU WANT TO PLAY AGAIN, TYPE Y/N.

HAPPY PLAYING!
